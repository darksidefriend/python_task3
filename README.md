# Глоссарий терминов с визуализацией MindMap

Проект представляет собой веб-приложение для управления глоссарием терминов с визуализацией связей между ними в виде графа (MindMap).

## Технологии

- Бэкенд: FastAPI, SQLite, SQLAlchemy
- Фронтенд: HTML, CSS, JavaScript, vis.js
- Контейнеризация: Docker, docker-compose
